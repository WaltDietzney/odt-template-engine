# Visual Regression Render Tool

This helper converts generated ODT sample outputs into PDFs and PNG page images for manual visual regression review.

It does **not** create, update, delete, or otherwise modify baseline artifacts.

## Requirements

- LibreOffice (`libreoffice`)
- Poppler (`pdftoppm`)

## Output directories

Generated artifacts are written to:

```text
tmp/visual-regression/
├── pdf/
└── images/
```

PDFs are generated by LibreOffice in headless mode. PNG page images are rendered by `pdftoppm` at 150 DPI.

## Render selected ODT files

From the repository root:

```bash
tools/visual-regression/render.sh \
    samples/output/output_05_replaceImage.odt \
    samples/output/output_21_cvProfile.odt
```

Each PDF is written to `tmp/visual-regression/pdf/`. Page images use the ODT basename as prefix, for example:

```text
tmp/visual-regression/images/output_21_cvProfile-1.png
```

## Render all generated sample outputs

When called without arguments, the script processes all matching files under `samples/output/`:

```bash
tools/visual-regression/render.sh
```

Render the desired sample PHP scripts first so that the corresponding ODT outputs exist.

## Safety

Before rendering an ODT, the helper removes only previously generated candidate PDF/PNG artifacts with the same basename from the two output directories above. Baseline archives and extracted baseline images are intentionally outside the script's responsibility and must remain unchanged.
