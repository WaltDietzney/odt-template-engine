# Legacy sample support fixtures

This directory contains historical numbered samples and their Writer templates
that remain useful for compatibility, architecture characterization, or
regression coverage. They are intentionally outside the public `samples/`
surface and are not part of the Sample Explorer or the canonical 1.0 taxonomy.

The canonical public path is L01–L12, C01–C05, B01–B02, S01b, S03, and S03-B.
