# H00: CV Integration Baseline

**Planning and integration milestone — no new public API**

H00 integrated the CV construction requirements with the existing ODT
Template Engine roadmap. It did not implement H01–H10, approve new API
methods, or change the release contract.

For application development, select the existing API by ownership:

- [Structured Content](structured-content/index.md) for PHP-built content;
- [Writer-native Objects](writer-native/index.md) for pre-authored named objects;
- [Programmatic Page Styles](template-document/page-styles.md) for page layout;
- [Native Section Authoring](structured-content/section-authoring.md) for H01;
- [Multi-page Layouts and Sidebars](template-document/sidebar-composition.md) for H02;
- [Native Drawing Shapes](structured-content/native-shapes.md) and
  [Skill Bars](structured-content/skillbars.md) for H03.

H00 is documented here so readers do not mistake the milestone number for
a missing PHP class. The historical planning and acceptance record is in
[H00 CV Baseline Integration](../architecture/H00_CV_BASELINE_INTEGRATION.md).
