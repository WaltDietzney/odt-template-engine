- Above-icon mode: unbacked icons; backed variants proven in vertical blocks.
- No automatic inference of available Section/frame width or font shrinking.
- Page-capacity overflow remains a rejection/fallback requirement, not solved
  pagination. Native field changes to empty require explicit recomposition.
- General Writer GUI selection/move/edit behavior has not been manually tested.

  processing and production resource identity remain integration gates.

  graphic style ownership for drawing children, and foreground/layer handling
  need bounded contracts in the existing components. Research adapters are not
  automatically adopted as new production classes.
- Timeline generic marker placement, component ownership and production
  lifecycle/edge cases remain implementation contracts, not new feasibility work.
